Scoring framework

Scoring methods

The calculator applies the frozen scoring rules and training-derived coefficients. It does not refit the original Cox or RCS models.

Primary score · β-weighted

RWDID

RWDID = Σ(Si × βi) / Σβi

Fifteen binary component indicators are combined using mutually adjusted Model 3 Cox coefficients estimated in the training cohort.

  • 15 binary components
  • Training-derived β weights
  • Range: 0–1
Complementary score · equal-weight

RWDID-C

RWDID-C = Σ Ci

Each component is mapped to a proportional score from 0 to 1 using its frozen target interval and training P1–P99 support.

  • 15 continuous component scores
  • Equal weights
  • Range: 0–15
