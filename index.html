Scoring framework

How the two scores are calculated

The browser uses the frozen component-specific intake rules, training-derived β coefficients, and continuous scoring parameters supplied with this repository.

Primary binary score

RWDID

RWDID = Σ(Si × βi) / Σβi

Each component is scored 0 or 1 according to its frozen intake interval. The 15 binary indicators are combined using the mutually adjusted training-cohort Model 3 Cox coefficients.

  • 15 binary components
  • Training-derived β weights
  • Score range: 0–1
  • No imputation
Continuous complementary score

RWDID-C

RWDID-C = Σ Ci

Each component is mapped to a continuous proportional score from 0 to 1 using its frozen target interval and training P1–P99 support. The 15 component scores are summed with equal weights.

  • 15 continuous components
  • Training-only P1–P99 support
  • Score range: 0–15
  • No imputation

UK Biobank access and rerun requirements. Individual-level UK Biobank data are not distributed in this public repository. Re-running the cohort-level analysis requires authorised UK Biobank access and the project-specific preprocessed data objects and source metadata listed in the consolidated analysis code. The included source blocks generate the frozen cohort split and the RCS20 interval anchors in sequence.

Research use only. RWDID and RWDID-C are dietary research indices. They are not validated clinical risk calculators, diagnostic tools, or prescriptive dietary recommendations. The calculator does not transmit questionnaire responses to a server.
