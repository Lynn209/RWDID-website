Input guide

The response controls follow the UK Biobank Oxford WebQ questionnaire and the corresponding Showcase data-coding, with the six continuous total-weight fields handled separately.

1. Select whether an item was consumed

For the 76 categorical Oxford WebQ fields, each food item is presented as a checkbox. Tick “Consumed yesterday” only when that item was eaten. Its amount selector then appears. An unticked categorical item contributes zero; zero is not an extra response category in the UKB coding.

2. Choose the original response category

Each categorical item displays its own UKB wording and category range. The options differ by data-coding: for example, vegetables use quarter/half/1/2/3+, fish and fruit use half/1/2/3/4+, and several drinks use half/1/2/3/4/5/6+.

3. Bread-roll type selector (Fields 101160 and 20094)

For the refined-grains white bread-roll item, first indicate whether any bread roll/bap/burger bun/hotdog roll/bagel was consumed, select all applicable types in Field 20094 (Data-Coding 81), and enter the Field 101160 amount. To reproduce the frozen Step_02_1_1 code exactly, the amount contributes to the derived white-bread item only when the selected type is exactly White (code 1) and no other type is selected. A selection of another type, or White together with another type, contributes zero to this derived item. This selector is a linked questionnaire field, not an additional dietary component.

4. Six fields are continuous grams/day

Fields 26102, 26131, 26133, 26151, 26152 and 26153 are UKB Showcase “Total weight by food group yesterday” fields with value type Continuous, g. They are not categorical Oxford WebQ item-response fields. Enter grams/day directly (enter 0 when there was no intake); the calculator divides by the corresponding Table S1 portion size.

5. Confirm no intake at group level

Use “No intake from this food group” only if none of the listed items in that component were consumed. Otherwise, tick each consumed item and complete its amount. Unselected items are treated as zero.

6. A note on the five grain fields

For fields with Showcase Data-Coding 100001, the released coding contains 555 = half, 1 = 1 and 200 = 2+. The frozen RWDID analysis maps code 200 to 2.0. Although the Oxford WebQ v1.5 appendix displays 2 and 3+ separately for these items, the released field coding does not distinguish those two values. To preserve compatibility with the analysed UKB fields and frozen R pipeline, this calculator displays one “2+” category and maps it to 2.0.

7. Recall period and interpretation

The original Oxford WebQ asks what was consumed yesterday. The research pipeline used available repeated 24-hour recall instances and averaged the item-level values. This browser calculator accepts one representative-day response per item; it does not recreate the repeated-instance averaging or impute missing days.

Source documents: UK Biobank 24-hour dietary recall questionnaire (Oxford WebQ), v1.5; Showcase Data-Coding 100017; 100006; 100004; 100003; 100016; 100001; Data-Coding 81 (bread type); Field 20094; Field 101160.
